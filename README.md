## ⚙️ Core Development Philosophy

I don't just write scripts; I engineer stable solutions. Every project, module, and UI update I build adheres to a strict, uncompromising workflow to ensure maximum performance and zero regressions.

**My Absolute Priorities:**  
`[ STABILITY ]` **>** `[ FUNCTIONALITY ]` **>** `[ RESPONSIVENESS ]` **>** `[ UI/UX ]` **>** `[ ANIMATION ]`

### The 9-Step Execution Protocol:
1. **Analyze:** Deeply comprehend the entire codebase before any modifications.
2. **Anticipate:** Proactively hunt for potential bugs, conflicts, and fragile features.
3. **Blueprint:** Plan the architectural changes thoroughly before writing a single line of code.
4. **Modernize:** Upgrade the UI to be clean and professional while strictly preserving all core functions.
5. **Review:** Conduct a meticulous post-code inspection.
6. **Stress Test:** Logically test every feature, event, navigation path, and responsive layout.
7. **Regression Check:** Ensure new implementations never break existing, working features.
8. **Patch & Re-test:** If a bug is found, squash it immediately and restart the testing loop.
9. **Zero-Trust Verification:** Never claim "0 Errors" or "0 Bugs" unless it has been ruthlessly verified.
